# Outpost

1v1 duel shooter in a single HTML file. Open [index.html](index.html) locally, or play the public build:

https://mrr4ndom29-code.github.io/outpost/

First to three rounds. Move with WASD, look with the mouse, shoot with left click, aim with right click. Space jumps, Shift sprints, C crouches, Z goes prone, R reloads, Q swaps shoulder, Esc pauses, M mutes sound.
