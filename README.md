# Outpost

1v1 duel shooter in a single HTML file. Open [index.html](index.html) locally, or play the public build:

https://mrr4ndom29-code.github.io/outpost/

First to three rounds. On a computer, move with WASD, look with the mouse, shoot with left click, and aim with right click. Space jumps, Shift sprints, C crouches, Z goes prone, R reloads, Q swaps shoulder, Esc pauses, M mutes sound.

On a phone, play in landscape. The left stick moves, dragging the right side looks around, and the on-screen buttons fire, aim, jump, sprint, crouch, go prone, reload, swap shoulder, pause, and mute.
